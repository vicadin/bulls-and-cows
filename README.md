# Bulls and Cows 🐂🐄

Bulls and Cows is a logic number-guessing game built in a functional programming style with multi-base support (`bin`, `oct`, `dec`, `hex`), real-time input validation, immutable attempt history, and a `localStorage` Hall of Fame.

## Demo

🌐 https://vicadin.github.io/bulls-and-cows/

## Tech Stack

- TypeScript
- Vite
- Vitest
- HTML5
- CSS3

## Installation & Execution

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```
